1. Скачана и установлена Apache Kafka

Скачан бинарный дистрибутив kafka_2.13-3.6.0.tgz. Распакован в C:\kafka\kafka_2.13-3.6.0.

2. Запущены ZooKeeper и Kafka

ZooKeeper запущен на порту 2181

Kafka брокер запущен на порту 9092

3. Создан топик airport

Тема выбрана в соответствии с заданием - «Аэропорт».

4. Написан скрипт Producer

Файл producer.py:

Генерирует сообщения о вылетающих самолетах (номер рейса, авиакомпания, пункт назначения, время вылета, статус, гейт)

Сообщение в формате JSON

Функция генерации вынесена отдельно (соблюдение SOLID)

Отправляет сообщения в топик airport

5. Написан скрипт Consumer

Файл consumer.py:

Подключается к топику airport

Получает сообщения

Проводит валидацию (проверка наличия полей, формата номера рейса, статуса, гейта)

Выводит валидные сообщения на консоль

При невалидных данных выводит сообщение и текст «NOT VALID»

6. Запущен Consumer

7. Запущен Producer

8. Проверена доставка сообщений

Сообщения успешно доходят от Producer к Consumer.

Результат работы:
Producer генерирует и отправляет 10 сообщений о рейсах в Kafka

Consumer получает сообщения, валидирует их и выводит на экран

При некорректных данных выводится NOT VALID
